# Системные настройки

Все настройки находятся в разделе «Системные настройки», пространство имён `tiptapeditor`. Их можно переопределить в настройках контекста, группы пользователей или пользователя. При обновлении пакета значения не сбрасываются.

Здесь только то, что почти каждый сайт меняет под себя. Меню, строка состояния, уровни заголовков, включение функций, защита тегов MODX и другое задаются в [профилях и внешнем JSON](./profiles#profile-keys). Редко нужные настройки собраны в разделе «Расширенные».

::: tip
Страница собирается автоматически из исходников пакета (`npm run docs:generate`).
:::

## Интерфейс

| Ключ | Описание | По умолчанию |
|---|---|---|
| <code>tiptapeditor.toolbar</code> | **Панель инструментов** Кнопки через пробел, группы через «\|», например undo redo \| heading \| bold italic \| link image. Пусто — панель пакета, в которой с обновлениями появляются новые кнопки. Кнопки, которых нет в списке, не показываются. | (пусто) |
| <code>tiptapeditor.profiles</code> | **Профили** JSON-объект именованных профилей, например {"simple": {"toolbar": "bold italic link"&#125;&#125;. Профиль «default» применяется ко всем полям, «content» — к полю content ресурса. Профиль задаёт панель, меню, уровни заголовков, функции и другое (см. документацию, «Профили»). | (пусто) |
| <code>tiptapeditor.tv_profiles</code> | **Профили TV** Имя TV → профиль: JSON-объект, например {"introtext": "simple"}, или пары имя=профиль по одной в строке или через запятую. | (пусто) |
| <code>tiptapeditor.content_css</code> | **CSS содержимого** Список CSS-файлов сайта через запятую для отображения содержимого в редакторе, например /assets/css/content.css,/assets/css/article.css. | (пусто) |
| <code>tiptapeditor.min_height</code> | **Минимальная высота** Минимальная высота области редактирования в пикселях. Редактор растёт вместе с содержимым до максимальной высоты. | <code>200</code> |
| <code>tiptapeditor.max_height</code> | **Максимальная высота** Максимальная высота области редактирования в пикселях, дальше появляется прокрутка. 0 — без ограничения. Значение, равное минимальной высоте, даёт фиксированную высоту. | <code>700</code> |

## Содержимое

| Ключ | Описание | По умолчанию |
|---|---|---|
| <code>tiptapeditor.iframe_allowed_hosts</code> | **Разрешённые хосты iframe** Список хостов, разрешённых в src у iframe (встраивание, видео в галереях), через запятую. Пусто — любой хост. | (пусто) |
| <code>tiptapeditor.image_classes</code> | **Пресеты классов изображений** Классы для изображений: JSON-объект {"css-класс": "Название"} или список классов через запятую. | (пусто) |
| <code>tiptapeditor.link_classes</code> | **Пресеты классов ссылок** CSS-классы для диалога ссылки: JSON-объект {"css-класс": "Название"} или список классов через запятую. Пусто — свободное текстовое поле. | (пусто) |
| <code>tiptapeditor.paragraph_classes</code> | **Пресеты классов абзацев** Классы для абзацев и заголовков (кнопка панели paragraphClass): JSON-объект {"css-класс": "Название"} или список классов через запятую. | (пусто) |
| <code>tiptapeditor.table_classes</code> | **Пресеты классов таблиц** CSS-классы в диалоге таблицы: JSON-объект {"css-класс": "Название"} (в одной записи можно несколько классов) или список через запятую. | (пусто) |
| <code>tiptapeditor.gallery_template</code> | **Шаблон галереи** Шаблон новых галерей: grid (сетка), slider (разметка Swiper), images (только изображения) или имя своего шаблона (имя файла в папке шаблонов галереи, без .html). | <code>grid</code> |
| <code>tiptapeditor.lightbox</code> | **Увеличение изображений по клику** Новые изображения и галереи получают ссылку на изображение вокруг картинки (&lt;figure&gt;&lt;a href="…"&gt;&lt;img&gt;&lt;/a&gt;&lt;/figure&gt;) для скрипта-лайтбокса на сайте. В диалоге включается и выключается для каждой картинки и галереи. | Нет |
| <code>tiptapeditor.lightbox_attribute</code> | **Атрибут лайтбокса** Атрибут, который ищет ваш скрипт-лайтбокс, например data-fancybox (Fancybox), data-lightbox. У одиночного изображения он без значения, у галереи — с именем группы (data-fancybox="gallery-3fa9c1"). Пусто — обычная ссылка. | (пусто) |

## Интеграция с MODX

| Ключ | Описание | По умолчанию |
|---|---|---|
| <code>tiptapeditor.fenom</code> | **Fenom** auto (по умолчанию): конструкции Fenom, например {$var} и {if}…{/if}, сохраняются без изменений; подсказки переменных включены, если pdoTools обрабатывает Fenom. 1 — защита и подсказки всегда. 0 — Fenom считается обычным текстом. | <code>auto</code> |
| <code>tiptapeditor.upload_enabled</code> | **Загрузка перетаскиванием и вставкой** Загружать перетащенные и вставленные в редактор изображения в источник файлов поля, в папку tiptapeditor.upload_path. Загрузка идёт через штатную загрузку MODX (право file_upload, политики источника, разрешённые типы файлов и upload_maxsize). Изображения никогда не сохраняются в base64. | Нет |
| <code>tiptapeditor.upload_path</code> | **Папка загрузки** Папка в источнике файлов поля для загружаемых изображений, например assets/uploads/ или assets/uploads/{y}/{m}/{id}/. Подстановки вроде {id}, {alias}, {y}, {m}, {rand} или {rand:8} перечислены в документации («Изображения, галереи, файлы»). | <code>assets/uploads/</code> |

## Система

| Ключ | Описание | По умолчанию |
|---|---|---|
| <code>tiptapeditor.external_config</code> | **Внешняя конфигурация** Путь к JSON-файлу с дополнительной конфигурацией и профилями, например {core_path}config/tiptapeditor.json. Читаются только данные, код не выполняется. | (пусто) |
| <code>tiptapeditor.debug</code> | **Режим отладки** Выводить диагностические сообщения в консоль браузера и журнал ошибок MODX. | Нет |

## Расширенные

| Ключ | Описание | По умолчанию |
|---|---|---|
| <code>tiptapeditor.gallery_templates_path</code> | **Папка шаблонов галереи** Папка с файлами шаблонов галереи, один .html файл на шаблон; имя файла — имя шаблона. Внутри core_path или base_path. Пакет один раз кладёт сюда свои шаблоны и никогда не перезаписывает и не удаляет файлы в этой папке. | <code>{core_path}elements/tiptapeditor/gallery/</code> |
| <code>tiptapeditor.fenom_tags</code> | **Дополнительные теги Fenom** Имена собственных тегов или функций Fenom через запятую (myTag, other), которые нужно защищать помимо встроенных ключевых слов (if, foreach, set, include, ...). | (пусто) |
| <code>tiptapeditor.links_across_contexts</code> | **Ссылки между контекстами** Нет (по умолчанию): поиск ресурса MODX в диалоге ссылки ищет только в контексте редактируемого ресурса. Да: во всех контекстах, доступных пользователю (кроме mgr). | Нет |
| <code>tiptapeditor.resource_link_format</code> | **Формат ссылки на ресурс** href для ресурса MODX, выбранного в диалоге ссылки. {id} — ID ресурса (обязательно); также заменяются {context} и {uri}. По умолчанию: [[~{id}]]. | <code>[[~{id}]]</code> |
| <code>tiptapeditor.media_source</code> | **Источник файлов** ID источника файлов для поля content ресурса. Пусто — default_media_source контекста. TV всегда используют свой источник. | (пусто) |
| <code>tiptapeditor.media_url_mode</code> | **Формат URL файлов** relative (по умолчанию) — URL в точности как вернул файловый менеджер MODX, как в TV «Изображение». root — к относительным URL добавляется base URL сайта (/assets/img/a.jpg). Абсолютные URL (S3 и другие удалённые источники) всегда сохраняются как есть. | <code>relative</code> |
| <code>tiptapeditor.upload_file_prefix</code> | **Имя загружаемого файла** Имя загружаемого изображения, например {id} даст 15.jpg (расширение сохраняется). Пусто: у файла остаётся своё имя. Если имя в папке уже занято, добавляется -1, -2 …. Те же подстановки, что в папке загрузки. | (пусто) |
