    details: Add images from the Media Browser, from your computer or by link, with captions and an "open larger" link for your lightbox script. Galleries use grid, slider or your own templates.

  - title: No CDN, no paid features
    details: Everything is bundled with the package. No Tiptap Cloud, no API keys, no paid extensions; the editor itself calls no third-party service.
