features:
  - title: HTML и теги MODX остаются как были
    details: Теги MODX и конструкции Fenom сохраняются символ в символ, разметку без визуального аналога редактор хранит отдельным HTML-блоком. Если открыть ресурс и сохранить без правок, в поле уйдёт ровно исходное значение.
  - title: Изображения, подписи и галереи
    details: Диалог изображения с alt, подписью, размерами, выравниванием и «увеличением по клику» для вашего лайтбокса. Галереи по шаблонам — сетка, слайдер Swiper или свои.
  - title: Таблицы
    details: Вставка через диалог, отдельная панель для строк, столбцов и объединения ячеек. Существующие таблицы сохраняются как написаны — с thead, tfoot, классами и атрибутами.
  - title: Профили и настройки
    details: Своя панель инструментов для каждого поля и TV, пресеты классов, CSS сайта внутри редактора, внешний JSON-файл конфигурации. Всё меняется в системных настройках, без пересборки.
  - title: Media Source и права MODX
    details: Файловый менеджер MODX, загрузка и поиск ресурсов работают через MODX и проверяют права пользователя, политики источника файлов и ACL групп ресурсов.
  - title: Без CDN и платных функций
    details: Всё собрано в пакет и грузится с вашего сайта. Никаких Tiptap Cloud, API-ключей и платных расширений.
